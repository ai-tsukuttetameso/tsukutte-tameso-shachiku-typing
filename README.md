# 社畜タイピング ～タイピングで会社を抜け出せ！～

会社の1日をタイピングでこなすゲームです。打ち間違えると「やり直し」で仕事が増えます。
YouTube「AIでつくってためそ」第8回で、**ChatGPT（Codex）×Claude 共同制作**で作りました。

▶ **遊ぶ：https://ai-tsukuttetameso.github.io/tsukutte-tameso-shachiku-typing/**

## 遊び方
- 朝→午前→昼→夕方→定時前の5ステージで、出てくる文をローマ字で打つ（shi/si、tsu/tu、n/nn などの揺れはどれでも正解。FAX・CC などの英字はそのまま打つ）
- 時間内に終わらなかった仕事は残業へ。終電（23:30）を逃すとタクシー代が引かれる
- 電話・上司の割り込み依頼・飲み会の誘いは、文を打って対応。疲労がたまると文字がかすんで揺れる。「コーヒー休憩」（PCはSpace）で回復
- 1日クリアで昇進（平社員→主任→課長→部長）。結果は「役職・称号」「社畜度○%」と給料明細で表示。部長で条件を満たすと…？
- 勤務モード：**ふつう**（1日 約4分＋残業最大3分）／**時短**（1日 約1分半＋残業最大1分）
- **一時停止はEscキー**（スマホは画面上の ⏸ ボタン）
- パソコンのキーボードが基本。スマホは入力欄をタップして英字キーボードで打てます

## 作り方
- 役割：ChatGPT（Codex）が仕様書とテスト・レビュー、Claudeが実装・テスト・修正
- `index.html` 1ファイルだけ（HTML・CSS・JavaScript）。画像ファイル・外部ライブラリなし
- 外部への通信は一切しません。打った内容も送信しません。進み具合と設定だけをブラウザのlocalStorageに保存します
